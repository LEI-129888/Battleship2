## 1. Especificação do Code Smell & Configuração

Para a implementação do Quality Gate automatizado, escolheu-se detetar o code smell "Long Method" utilizando a inspeção estática do Qodana em projetos Java (Maven, OpenJDK 21).

- **Inspection ID:** NonCommentSourceStatements

- **Limiar (Threshold) Configurado:** 16 linhas (entre o alto e muito-alto apresentado no guião)

Ficheiros de Configuração Criados:

- qodana-129888.yaml (na raiz do repositório)

- .qodana/profiles/profile-129888.yaml (perfil customizado com o limiar de linhas)

- .github/workflows/qodana-smell-129888.yml (pipeline do GitHub Actions com suporte a Pull Request)

## 2. Evidências do Quality Gate (GitHub Actions)

O ciclo de testes do Quality Gate exigiu a validação de que o pipeline bloqueia falhas de métrica e passa com sucesso após a respetiva refatoração:

## 3. Conclusão

A integração do Qodana em modo de Pull Request permitiu monitorizar de forma incremental a qualidade do código, avaliando apenas as alterações sem ter em conta o código já presente na branch main. 
O Quality Gate provou ser eficaz a automatizar a verificação do limite de linhas para o smell "Long Method" sem qualquer falso positivo ou falso negativo.
