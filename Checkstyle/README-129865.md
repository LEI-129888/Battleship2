### Reflexão
O Checkstyle é muito útil para nos forçar a seguir as convenções de código, como a regra `ConstantName` escolhida para as variáveis estáticas. No entanto, tem uma limitação óbvia: como apenas valida o formato do texto através de expressões regulares, não compreende realmente a semântica do código. 
Ou seja, a ferramente não consegue avaliar realmente se o nome que damos à variável faz efetivamente sentido para a lógica do jogo ou se é um nome completamente irrelevante, desde que respeite a regra das maiúsculas.
